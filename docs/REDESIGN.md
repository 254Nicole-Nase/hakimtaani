# HakiMtaani redesign — phase 1

Direction: a neighbourhood legal desk, not an AI chatbot landing page.

Warm paper / forest / clay palette, system serif editorial headings (no external font downloads), shared responsive navigation and situation-first homepage. Existing routes, case engine, citations, AI providers and metrics remain unchanged. 

## Review gates

- Typecheck, unit tests and Vercel build via existing CI.
- Inspect preview at 360px, 768px and desktop widths; check navigation overflow, keyboard focus, active route, chat height and scrolling.
- Walk through employment and tenancy flows, contract upload/paste, chat and voice, help and impact.
- Verify claims of legal correctness and privacy against actual implementation.
- Phase 2: case intake, fact confirmation, urgent deadlines, result hierarchy and accessible sources.
- Phase 3: letter preview, validation, export, chat and contract review.
- Phase 4: localisation, accessibility and privacy review.

No production merge before review.
